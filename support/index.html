Orbit support

How can we help?

Start with the answers below. For a bug report, include your browser, Orbit version, exact error, and any request ID—but never include passwords, API keys, payment cards, Google credentials, or an Orbit bearer token.

Report an issue →
Orbit cannot read the current page

Browser settings, extension stores, new-tab pages, protected viewers, and some internal pages cannot be accessed. Open a regular HTTPS webpage, select Attach current page, and approve access if prompted.

A file will not upload

Orbit accepts up to three supported files. Images and PDFs can be up to 4 MB each, text-based files up to 250 KB each, with an 8 MB combined limit.

Google sign-in does not return to Orbit

Close the sign-in window, reopen Orbit, and try again. Ensure popups are allowed and your browser is not blocking the extension identity redirect.

Paid access is missing

Sign in with the same Google account used for Orbit, open the account menu, and select Refresh subscription. Paid access follows that verified account across reinstalls.

How do I cancel?

Open the signed-in account menu, select Manage subscription, and cancel through Stripe. Deleting the Orbit account instead cancels immediately and permanently removes eligible Orbit data.

How do I delete my data?

Delete conversations or Spaces individually, sign out to retire the current installation, or use Delete account for permanent account-wide deletion. Stripe may retain billing records where legally required.
